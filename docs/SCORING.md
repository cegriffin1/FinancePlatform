# Scoring

## Three separate concepts

| Concept | Answers |
|---------|---------|
| Opportunity Score (0–100) | How valuable/qualified is this opportunity? |
| Temperature | How ready is this prospect right now? |
| Completion | How much intelligence did we collect? |

Completion uses **applicable** questions (branch-aware), not a blind 24.

## Asset tiers (normalized cents)

- BELOW_TARGET: under $250K
- GOLD: $250K–$999K
- DIAMOND: $1M–$2.99M
- BLACK: $3M+

Self-reported bands are never treated as third-party verified. Setter confirmation → `SETTER_CONFIRMED`.

## Versions stamped on leads

- Assessment template version
- Opportunity / temperature score versions
- Consent text + consent version

## Partial profiles

Incomplete assessments still score. High assets + strong intent can outrank a complete low-value profile.
