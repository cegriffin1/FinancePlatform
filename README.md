# Growth Operating System

Multi-tenant, AI-powered Growth Operating System for businesses — industry-neutral core with Advanced Markets as the first accelerator.

## Quick start

```bash
cp .env.example .env.local
npm install
npm run dev
```

See [docs/development-setup.md](./docs/development-setup.md) and the full documentation suite under [`docs/`](./docs/).

## Stack

Next.js App Router · TypeScript (strict) · Tailwind CSS · Supabase · React Hook Form · Zod · Vitest · Playwright
